# 🔥 TSK-Multi Data Selector 🔥

TSK-Multi Data Selector라는 프로그램은 파이썬 기반의 GUI 프로그램으로, TSK-Multi를 이용해서 수집한 데이터에서 원하는 센서의 값만 추출하는 프로그램입니다. `.exe` 실행 파일로 배포하고 있으며, 여러 실험에서 측정된 값들에서 원하는 센서의 번호만 추출하는 반복 작업을 보다 빠르게 하도록 도와주는 역할을 합니다.

## 🔭 기능 소개

➕ 간단하고 직관적인 유저 그래픽 인터페이스  
➕ 파일 목록 추가, 삭제, 초기화 기능 제공  
➕ 드래그 앤 드랍으로 여러 개의 파일을 한번에 추가 가능  
➕ 환경 설정을 통해 추출하고 싶은 센서 번호를 선택하여 추출할 수 있음  
➕ 선택한 센서 번호는 저장되어 실행할 때마다 선택할 필요 없음  
➕ 설치 파일이 아닌 실행 파일로 제공하여 포터블로 사용
